# XASM 2026-4

Note de cadrage du port C# natif de XASM2026.

Cette version prend `xasm2026-1` comme **référence fonctionnelle** et `xasm2026-2` comme étape
de transition. L'objectif était de remplacer le moteur C par du code C# natif sans perdre une
seule des options, directives et sorties déjà validées.

> Pour l'usage courant, voir [`README.md`](README.md). Ce document ne conserve que le cadrage
> et l'état d'avancement ; le journal détaillé est dans [`PORTAGE.md`](PORTAGE.md).

## Contenu

```text
src/                         Projet C# natif
bin/                         Exécutable de commodité, recopié à la main
Documentation/               Documentation du projet
Documentation/XASM2026-1/    Documentation de référence héritée
Exemples/                    Sources et sorties de référence
Reference/C/                 Sources C d'origine + xasm2026-1-2.exe
Reference/CSharpWrapper/     Trace de l'étape xasm2026-2
tests/                       Harnais xUnit et fichiers de couverture
tools/                       Comparaison avec la référence, génération de doc
```

## Compilation

```powershell
dotnet build .\src\Xasm2026.Native.csproj -c Release
```

L'exécutable canonique est produit dans `src/bin/Release/net8.0/xasm2026-4.exe` ; une copie de
commodité est maintenue dans `bin/`.

## État actuel

**Le portage est terminé et vérifié.** Le cœur assembleur SC62015 est entièrement écrit en C#,
et le moteur C n'est plus utilisé à l'exécution — il ne sert que de référence.

### Conformité au moteur C

Le 2026-07-19, les sorties de `xasm2026-4` ont été confrontées directement à celles de
`xasm2026-1-2.exe`, dans des répertoires isolés et avec des arguments identiques :

| Source | Code produit | Résultat |
|---|---:|---|
| `SAMPLE1` à `SAMPLE5` | 64, 77, 25, 6, 30 o | identique |
| `REGISTER` | 4 154 o | identique |
| `TMAP2020` | 1 744 o | identique |
| `VOGUE` | 14 433 o | identique |

Le `.uu` diffère par une ligne finale `size` et le bourrage du dernier bloc : c'est le choix
délibéré de reproduire `uuselfx.c` et les sorties DOSBox, documenté au journal du 2026-06-04.
Les deux fichiers décodent vers le même objet.

### Non-régression automatisée

`tests/Xasm2026.Tests` réassemble les quatre exemples de référence et compare les **huit**
sorties octet à octet — 32 comparaisons exactes — auxquelles s'ajoutent les tests de
comportement, d'évaluation d'expressions, de table des symboles et de directives.
La CI GitHub Actions exécute l'ensemble à chaque push, sur `windows-latest`.

### Au-delà du moteur C

`xasm2026-4` ajoute des fonctionnalités absentes de la lignée C, toutes **purement
additives** : un source qui ne les emploie pas produit exactement les mêmes octets.

- Symboles redéfinissables `SET` / `=`, qui rendent `REPEAT` réellement génératif.
- Répétition sur liste et sur chaîne : `IRP`, `IRPC`, imbricables avec `REPEAT`.
- `EXITM`, macros imbriquées et `REPEAT` dans un corps de macro.
- Opérateurs `^ ~ << >>` et comparaisons, extraction d'octets `LOW` / `MID` / `HIGH`.
- `ALIGN` / `EVEN`, `DZ`, `ASSERT` / `ERROR` / `WARNING`.
- `PHASE` / `DEPHASE` pour le code assemblé à une adresse et exécuté à une autre.
- Table des références croisées (`-U`), `TITLE` / `LIST` / `NOLIST` / `PAGE`.

Les exemples `SAMPLE6` à `SAMPLE9` les illustrent. Ils n'assemblent volontairement pas avec
`xasm2026-1` et sont exclus de la comparaison avec la référence.

### Garde-fous ajoutés

Plusieurs défauts silencieux ont été corrigés en cours de portage — ils produisaient un binaire
faux sans le signaler, ce que ce projet cherche avant tout à éviter :

- symbole indéfini et division ou modulo par zéro sont désormais des erreurs fatales ;
- une étiquette d'adresse dupliquée dans la même portée est rejetée (code 13 du moteur C) ;
- `LOCAL` sans étiquette ouvre une portée anonyme, ce qui rend uniques les étiquettes d'un
  corps de macro expansé plusieurs fois ;
- les inclusions cycliques sont détectées.

## Stratégie suivie

Le port a avancé par blocs vérifiés, chaque étape gardant les exemples comme tests de
non-régression :

1. Tables d'initialisation, hachage des mnémoniques et symboles.
2. Lecture source, includes, macros et conditions.
3. Évaluation d'expressions.
4. Encodage des opérandes et opcodes SC62015.
5. Directives historiques et directives 2026.
6. Formats de sortie objet, listing et sorties modernes.
7. Comparaison octet à octet avec les exemples, puis avec le moteur C lui-même.
