# XASM 2026-4

Developpement dedie au port C# natif de XASM2026.

Cette version repart de `xasm2026-1` comme reference fonctionnelle et de `xasm2026-2` comme etape de transition. L'objectif de `xasm2026-4` est de remplacer progressivement le moteur C par du code C# natif, sans perdre les options, directives et formats de sortie deja valides.

## Contenu

```text
src/                         Projet C# natif
bin/                         Executable C# natif compile
Documentation/XASM2026-1/    Documentation de reference
Exemples/                    Sources et sorties d'exemple
Reference/C/                 Sources C originaux utilises pour le port
Reference/CSharpWrapper/     Trace de l'etape xasm2026-2
tests/                       Outils et notes de non-regression
```

## Compilation

Depuis le dossier `xasm2026-4` :

```powershell
dotnet build .\src\Xasm2026.Native.csproj -c Release
```

L'executable est genere ici :

```text
src/bin/Release/net8.0/xasm2026-4.exe
```

Une copie pratique est aussi placee dans :

```text
bin/xasm2026-4.exe
```

## Etat actuel

Le projet C# natif reconnait l'interface de commande historique et porte deja une premiere partie des sorties modernes :

```text
CommandLineOptions.cs      Options XASM historiques et 2026
Assembly/NativeAssembler.cs Premier noyau assembleur C# autonome
Outputs/IntelHexWriter.cs  Sortie Intel HEX
Outputs/SRecordWriter.cs   Sortie Motorola S-Record
Outputs/HxdDumpWriter.cs   Dump texte type HxD
Outputs/BasicUuWriter.cs   BASIC uuencode auto-decodable
```

Le premier noyau autonome sait assembler `SAMPLE5` pour les sorties `.hex` et `.s19` avec un resultat identique a la reference.

Le reste du coeur assembleur SC62015 reste a porter depuis `Reference/C`, notamment l'ensemble complet des opcodes, macros, includes et listing historique.

## Strategie

Le port doit avancer par blocs verifies :

1. Tables d'initialisation, hash des mnemonics et symboles.
2. Lecture source, includes, macros et conditions.
3. Evaluation d'expressions.
4. Encodage des operandes et opcodes SC62015.
5. Directives historiques et directives 2026.
6. Formats de sortie objet, listing et sorties modernes.
7. Comparaison bit a bit avec les exemples.

Chaque etape doit garder les exemples comme tests de non-regression.
