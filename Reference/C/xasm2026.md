# XASM 2026-1

Assembleur croise pour le CPU SC62015 / ESR-L utilise par les Sharp PC-E500 et PC-E500S.

Cette version part de XASM 1.40 en C et ajoute des sorties modernes, des directives assembleur supplementaires et une generation `.uu` BASIC auto-decodable pour PC-E500S.

## Contenu

```text
xasm2026-1.exe   Executable Windows x64
*.c, *.h         Sources C de l'assembleur
modern.c         Extensions 2026-1
Exemples/        Sources et sorties d'exemple
```

Le dossier ne depend pas de .NET ni de Visual Studio.

## Compilation

Depuis le dossier `xasm2026-1` :

```powershell
gcc -std=c99 -Wall -Wextra -Wno-pointer-sign -Wno-sign-compare -o xasm2026-1.exe eval.c genop.c hash.c init.c mes.c misc.c modern.c mvopr.c opr.c var.c xasm.c
```

Avec GCC 14, cette commande compile sans message d'avertissement.

`-Wno-pointer-sign` et `-Wno-sign-compare` masquent deux familles de warnings dues au code historique, qui manipule les chaines en `unsigned char`.

## Utilisation

```text
xasm2026-1.exe sourcefile[.ext] [options]
```

Options historiques :

```text
-L[fichier]   Genere un listing
-E[fichier]   Rapport d'erreurs avec listing
-O[fichier]   Genere le fichier objet principal
-S            Ajoute la table des symboles au listing
-T[type]      Type d'objet principal :
              Z = format ZSH texte PC-E500
              B = binaire brut
              H = hexadecimal ASCII
              F = format FTX
              autre ou absent = binaire avec en-tete XASM 16 octets
-C            Affiche le compteur de lignes pendant l'assemblage
-W            Affiche aussi les warnings
-H            Desactive le hachage des symboles
```

Options ajoutees :

```text
-I[fichier]   Genere un Intel HEX
-M[fichier]   Genere un Motorola S-Record .s19
-P[fichier]   Genere une MAP avec symboles et sections
-D[fichier]   Genere un fichier de dependances
-B[fichier]   Genere un BASIC uuencode auto-decodable .uu
-X[fichier]   Genere un dump texte de type HxD .txt
-V            Ajoute une indication de colonne aux erreurs
-R            Affiche le rapport de taille par SECTION
```

Les options avec fichier acceptent les deux formes :

```powershell
xasm2026-1.exe SAMPLE5.ASM -OSAMPLE5.obj -LSAMPLE5.lst
xasm2026-1.exe SAMPLE5.ASM -O SAMPLE5.obj -L SAMPLE5.lst
```

## Exemples

Depuis `Exemples\SAMPLES` :

```powershell
..\..\xasm2026-1.exe SAMPLE5.ASM -O SAMPLE5.obj -L SAMPLE5.lst -TZ -I SAMPLE5.hex -M SAMPLE5.s19 -P SAMPLE5.map -D SAMPLE5.d -B SAMPLE5.uu -X SAMPLE5.txt -R -W
```

Depuis `Exemples\VOGUE` :

```powershell
..\..\xasm2026-1.exe VOGUE.S -O VOGUE.obj -L VOGUE.lst -I VOGUE.hex -M VOGUE.s19 -P VOGUE.map -D VOGUE.d -B VOGUE.uu -X VOGUE.txt -R -W
```

## Sorties

### Objet principal `-O`

Sans `-T`, le fichier objet contient l'en-tete XASM de 16 octets suivi du code assemble.

Avec `-TZ`, la sortie `-O` est au format ZSH texte PC-E500 :

```text
----- ZSH FOR E500 [A.OUT]
---( n lines )---
...
( end of line )
```

### Intel HEX `-I`

Format texte standard avec adresses et checksum :

```text
:10E000000000000056FF01080009024...
:00000001FF
```

### Motorola S-Record `-M`

Format S19 avec enregistrements `S1` :

```text
S0030000FC
S113E0000000000056FF01080009024...
S9030000FC
```

### MAP `-P`

La MAP contient :

```text
; XASM MAP file - source
; Code: debut - fin [taille]

; Sections:
;   NOM  debut  fin  taille

; Symbols:
adresse  symbole
adresse  symbole!local
```

La section `Sections` reste vide si le source n'utilise pas `SECTION`.

### Dependances `-D`

Format compatible make :

```make
VOGUE.obj: VOGUE.S runtime.s screen.s compile.s main.s database.s
```

### BASIC uuencode `-B`

Genere un fichier BASIC auto-decodable inspire de `uuselfx.c`.

Si `-O` est utilise, le `.uu` encode le fichier objet genere par `-O`. Sinon, il encode les octets machine produits par l'assemblage.

Le nom dans `FNAME$` est converti au format 8.3 en majuscules et complete par des espaces :

```basic
130   FNAME$="VOGUE   .OBJ"
```

Les lignes du decodeur machine sont au format :

```basic
290 '%DMKMKBPPALCMAECGPPBOADACAEPPIMKBPPALJACEGAGCBLBCJACEGAGFBLBIJACE
...
420 '#
```

### Dump HxD `-X`

Genere un fichier texte lisible avec une presentation proche de l'export HxD :

```text
Offset(h) 00 01 02 03 04 05 06 07 08 09 0A 0B 0C 0D 0E 0F

00000000  FF 00 06 01 10 61 38 00 00 98 0B FF FF FF 00 0F  .....a8.........
```

Si `-O` est utilise, le dump `-X` est produit a partir du fichier objet complet, en-tete inclus. Sinon, il est produit a partir des octets machine generes.

## Directives ajoutees

### REPEAT / ENDR

Repete un bloc a l'assemblage.

```asm
REPEAT  4
NOP
ENDR
```

### IFEQ / IFNE / IFGT / IFLT

Conditionnels bases sur une expression numerique.

```asm
VERSION: EQU 2

IFEQ VERSION-2
DB 056H
ENDIF

IFNE VERSION-1
DB 0FFH
ENDIF

IFGT VERSION-1
DB 001H
ENDIF

IFLT VERSION-5
DB 002H
ENDIF
```

### STRUCT / ENDS

Definit une taille de structure sous la forme `NOM_SIZE`.

```asm
POINT:      STRUCT
POINT_X:    EQU 0
POINT_Y:    EQU 1
            ENDS

; POINT_SIZE vaut 2
```

### SECTION

Marque une zone pour le rapport `-R` et la MAP.

```asm
SECTION INIT
; code init

SECTION MAIN
; code principal
```

## Notes de compatibilite

Les directives historiques de XASM 1.40 restent disponibles : `ORG`, `END`, `EQU`, `LOCAL`, `ENDL`, `DB`, `DM`, `DW`, `DP`, `DS`, `INCLUDE`, `MACRO`, `ENDM`, `DEF`, `UNDEF`, `IFDEF`, `IFNDEF`, `ELSE`, `ENDIF`, `PRE_ON`, `PRE_OFF`, `PRE_PUSH`, `PRE_POP`, `SCOPE_ON`, `SCOPE_OFF`.

Le code source assembleur doit toujours se terminer par `END`.
