# XASM 2026-2 C#

Version isolee de XASM2026 pour un developpement C#.

Cette premiere version fournit une application console C# `xasm2026-2` qui conserve l'interface et toutes les sorties de `xasm2026-1` en utilisant le moteur assembleur valide comme moteur embarque.

## Contenu

```text
src/                 Projet C# .NET
bin/                 Executable C# pret a utiliser
Engine/              Moteur XASM2026 de reference embarque
Documentation/       Documentation copiee depuis xasm2026-1
Exemples/            Exemples et sorties de reference copies depuis xasm2026-1
```

## Compilation

Depuis le dossier `xasm2026-2` :

```powershell
dotnet build .\src\Xasm2026.CSharp.csproj -c Release
```

L'executable C# est genere ici :

```text
src/bin/Release/net8.0/xasm2026-2.exe
```

Le moteur embarque `xasm2026-engine.exe` est copie automatiquement dans le meme dossier de sortie.
Une copie prete a utiliser est egalement placee dans `bin/`.

## Utilisation

L'interface reste identique a `xasm2026-1` :

```powershell
xasm2026-2.exe sourcefile[.ext] [options]
```

Exemple depuis `Exemples\SAMPLES` :

```powershell
..\..\bin\xasm2026-2.exe SAMPLE5.ASM -O SAMPLE5.obj -L SAMPLE5.lst -TZ -I SAMPLE5.hex -M SAMPLE5.s19 -P SAMPLE5.map -D SAMPLE5.d -B SAMPLE5.uu -X SAMPLE5.txt -R -W
```

## Options conservees

Toutes les options de `xasm2026-1` sont transmises au moteur :

```text
-L[fichier]   Genere un listing
-E[fichier]   Rapport d'erreurs avec listing
-O[fichier]   Genere le fichier objet principal
-S            Ajoute la table des symboles au listing
-T[type]      Type d'objet principal
-C            Affiche le compteur de lignes
-W            Affiche aussi les warnings
-H            Desactive le hachage des symboles
-I[fichier]   Genere un Intel HEX
-M[fichier]   Genere un Motorola S-Record .s19
-P[fichier]   Genere une MAP
-D[fichier]   Genere un fichier de dependances
-B[fichier]   Genere un BASIC uuencode auto-decodable .uu
-X[fichier]   Genere un dump texte HxD .txt
-V            Ajoute une indication de colonne aux erreurs
-R            Affiche le rapport de taille par SECTION
```

## Maintenance

Le dossier `xasm2026-2` est volontairement autonome. La documentation et les exemples sont presents localement pour faciliter les comparaisons de sorties et les futures evolutions.

La prochaine etape naturelle consiste a remplacer progressivement le moteur embarque par des classes C# natives, en conservant les exemples comme tests de non-regression.
